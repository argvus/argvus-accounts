# Security Policy

Only the latest tagged release is actively supported. Please report
vulnerabilities privately through [GitHub Security Advisories](https://github.com/argvus/argvus-accounts/security/advisories/new)
instead of opening a public issue.

Include the affected version, reproduction steps, impact, and (when possible)
a suggested fix. The package is GPG-signed when published to the ARGVUS
package repository.
